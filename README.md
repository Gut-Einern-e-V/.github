# Gut Einern e.V. – .github

This repository contains the **public organisation profile** for [Gut Einern e.V.](https://www.gut-einern.org/) on GitHub.

The profile page visible to everyone on the organisation's GitHub page is located in [`profile/README.md`](./profile/README.md).

---

Gut Einern e.V. is a non-profit association in Wuppertal, Germany, building a regional transformation centre for sustainable living, working, and learning. We are a founding member of [FAB.Region Bergisches Städtedreieck](https://www.fab-bergisch.org/) — Germany's first FAB Region — and committed to open source, open knowledge, and community-driven innovation.
